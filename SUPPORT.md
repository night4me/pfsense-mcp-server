# Support

## Reporting a bug

Open a [bug report issue](https://github.com/night4me/pfsense-mcp-server/issues/new?template=bug_report.yml).
Never include credentials, real appliance identifiers, raw responses, or
unsanitized logs — see [CONTRIBUTING.md](CONTRIBUTING.md) for the synthetic
placeholder conventions this project uses throughout.

## Reporting a security vulnerability

Do not open a public issue. Follow [SECURITY.md](SECURITY.md)'s private
reporting process instead.

## Asking a question or proposing an idea

Open a [feature request issue](https://github.com/night4me/pfsense-mcp-server/issues/new?template=feature_request.yml)
for a proposal, or search existing issues first — many questions about
scope, architecture, or the v0.3.0 Tier 1 safety framework's current state
are already answered in the documentation below.

## Documentation

- [README](README.md) — installation, configuration, quick start,
  troubleshooting the running server.
- [CONTRIBUTING.md](CONTRIBUTING.md) — development setup, workflow, and
  troubleshooting the development environment.
- [`docs/`](docs/) — architecture, security model, threat model, API
  reference, and the full v0.3.0 design record (Architecture Decision
  Records and subsystem specifications).

This project does not offer paid or commercial support.
